### 5-2. 적용 방안과 실행 방법

**① 레퍼런스 → DESIGN.md**: 모든 크리에이티브 작업의 단일 기준
1. 레퍼런스 3개를 수집합니다. 무료 경로는 Refero Styles, 유료 경로는 Refero MCP입니다.
2. 아래 프롬프트로 DESIGN.md를 합성합니다.
3. `npx @google/design.md lint DESIGN.md`로 검사합니다.
4. CLAUDE.md에 "UI·홍보물 작업 전 DESIGN.md를 읽고, 토큰 밖의 색·폰트는 쓰지 말 것"을 추가합니다.

```text
[입력] references/ 의 레퍼런스 3개, brief.md(업종·타깃·가게 컨셉)
[작업] 1) 레퍼런스별 색 hex·타이포 위계·여백 스케일·모서리·컴포넌트 패턴을 표로 추출
       2) 우리 브랜드 색 #______ 를 primary로 고정, 나머지는 레퍼런스에서 조합
       3) DESIGN.md 형식(YAML 토큰 + Overview/Colors/Typography/Layout/Components/Do's and Don'ts)으로 작성
[금지] 특정 브랜드 1곳 복제, 레퍼런스의 로고·카피·사진·일러스트 사용
```

**② 레퍼런스 기반 랜딩·포트폴리오**: 생성 → 스크린샷 → 자가 점검 루프

```text
DESIGN.md를 먼저 읽어. brief.md 기준으로 단일 index.html 랜딩을 만들어.
섹션: 히어로(한 줄 가치제안+CTA) → 고객 문제 → 해결/메뉴 → 후기 → 위치·영업시간 → CTA.
모바일 360px 우선, 라이트/다크 지원. 완성 후 360px·1280px 스크린샷을 찍고
DESIGN.md의 Do's/Don'ts 항목별 점검표를 채운 뒤 위반 항목을 수정해.
```

**③ 포트폴리오 콘텐츠화**(0:57:12 질문 대응)
- `portfolio/raw/<프로젝트>/` 폴더마다 case.md(문제-역할-과정-결과), 인스타 캐러셀 5장 카피, 카드 JSON을 만듭니다.
- 폴더에 없는 사실은 `[확인 필요]`로 표시합니다.

**④ 이미지 리서치**
- 출처와 라이선스가 달린 `moodboard.md`를 만듭니다. 형식은 표이고, 공통 패턴 5개와 피할 패턴 3개를 정리합니다.
- 수집한 이미지는 참고만 하고 게시물에 쓰지 않습니다.

**⑤ 홍보물(정적)**
- 한글 텍스트를 이미지 모델에 맡기지 않습니다. **HTML 템플릿 + 토큰 + Playwright 렌더**로 만들면 가격·기간이 깨지지 않습니다.
- 변수는 `{상품명}{정가}{할인가}{기간}{사진}`입니다. 1080×1350, 1080×1920, A4 세 가지를 한 번에 렌더합니다.

**⑥ 사진 → 영상**(2단계)
1. `higgsfield generate cost`로 비용을 먼저 확인합니다.
2. 키프레임을 만들고, `generate create ... --aspect_ratio 9:16 --duration 5 --wait --json`으로 클립을 생성합니다.
3. ffmpeg로 편집합니다.
4. 시안은 여러 개 만들고, 최종 선택은 사람이 합니다.

CLI는 v0.1.x이므로 명령이 바뀔 수 있습니다.

|---|---|---|---|---|
| 난이도 | 터미널 없는 **Lv0 트랙** 분리 | 등록 폼에 3문항(업종, 사용 도구, AI 경험)을 넣고 세션에 난이도 라벨을 붙입니다 | 2주 | "어렵다"류 채팅 5% 미만 |
| 카피 | 설명란 구조(막막함 → 낭비 → 가능성 → 직원)를 차용 | 랜딩 템플릿: 문제 3줄 → 대상 체크리스트 → 무료 자료 → CTA | 1주 | 랜딩 → 등록 30% |
| 제품 소개 | 기능 목록 대신 **직무기술서(JD)** 형식 | 업종별 JD 카드 5종 제작(예: "주 3회 블로그, 매일 인스타, 매주 전단") | 2주 | 데모 신청률 |
| 사회적 증거 | 업종별 **전후 비교 사례** | 파일럿 매장 10곳에 무료 제작 → 후기 동의 → 카드뉴스 | 4주 | 사례 10건 |
| 리텐션 | 중간 체크포인트 3회, 폼은 종료 20~30분 전 공개 | 큐시트에 CTA 시점 고정, 고정 메시지와 QR 병행 | 즉시 | 폼 공개 시점 잔존율 60% |
| 리드 마그넷 | 업종별 템플릿 팩과 후기 교환 | Tally → 이메일·알림톡 자동 발송 | 1주 | 폼 제출 ÷ 피크 동접 25% |
| 유료 전환 | 7일 이내 전환 이벤트, **온라인 동시 옵션** | 결제 페이지와 얼리버드 D-day 설정 | 2주 | 폼 대비 결제 5~10% |
| 게스트 | 월 1회 비기술 게스트(브랜딩·인문·업종) | 게스트 채널과 교차 홍보 | 월 1회 | 신규 구독 증가 |

## 7. 우리 서비스 적용·확장 (통합안)

> **가정**: `papascompany/marketing_ai`는 현재 초기 설정 파일만 있고 서비스 코드가 없습니다. 그래서 서비스를 **"중소상공인·1인 대표를 위한 AI 마케팅 자동화 SaaS"**로 가정했습니다. 기술 스택(Next.js/Vercel + Supabase)은 조직에 연결된 커넥터를 근거로 추정했습니다. 가격과 KPI는 모두 검증 전 가설입니다.

### 7-1. 포지셔닝과 세그먼트

- **컨셉(본질 + 특성)**
  - 본질: "사장님이 가게에 집중해도 손님이 계속 알게 된다"
  - 특성: "우리 가게를 익힌 AI 마케팅 직원이 매주 콘텐츠를 만들고 올린다"
- **포지셔닝**: 마케팅 인력이 없는 매장과 1인 대표를 위한, **배우지 않아도 쓰는 AI 마케팅 직원**
- **경쟁 구도**
  - 교육형(윤자동, QJC 등): "배워서 직접 만든다"
  - 도구형(Canva, 미리캔버스): "직접 조작한다"
  - 대행사: 비싸다
  - 우리: **대행 수준의 결과를 도구 가격에**
- **세그먼트 우선순위**
  1. 오프라인 매장(편의점·카페·음식점·미용)
  2. 1인 크리에이터·프리랜서, 소규모 셀러
  3. AI 교육을 수강했지만 실행하지 못한 층(교육 사업자와 B2B2C 제휴)
  - 초기 제외: 개발자·고급 사용자

### 7-2. 아키텍처

```text
[대표님] ─ 웹 대시보드(Next.js/Vercel) ─┐
         └ 메신저 봇(카카오/텔레그램) ──┤
                                         ▼
                   Orchestrator (Claude Agent SDK)
     ┌───────────┬───────────┬───────────┬───────────┐
   전략(CMO)   카피라이터   디자이너     리서처     성과분석
     └───────────┴─────┬─────┴───────────┴───────────┘
                Skills 라이브러리(업종 템플릿)
                        │
  크리에이티브 파이프라인
  ① 브랜드 킷(DESIGN.md) → ② 레퍼런스 리트리버(업종 라이브러리)
  → ③ 생성 엔진 [정적: HTML 템플릿+토큰 렌더 | 사진: 보정·누끼 | 영상: 크레딧 과금]
  → ④ 디자인 QA 게이트 → ⑤ 멀티 포맷 → ⑥ 사장님 모바일 승인 → ⑦ 게시·인쇄
  → ⑧ 성과 수집 → ②③ 가중치 피드백
                        │
  Supabase: 브랜드 킷 · 콘텐츠·승인 로그 · 리드 CRM · 비용 원장
```

- **모델 라우팅**: Opus 5.5는 전략·브리프·DESIGN.md, Sonnet 5는 카피 대량 생성, Haiku 4.5는 분류·금칙어 검사를 맡습니다.
- **플랫폼 제약**:
  - 인스타그램은 Graph API(비즈니스 계정) 범위에서만 게시할 수 있습니다.
  - 네이버 블로그는 공식 쓰기 API가 제한적이라, 초안을 내보낸 뒤 수동으로 게시하는 흐름으로 설계합니다.

### 7-3. 디자인 QA 게이트

| 검사 | 방법 | 기준 |
|---|---|---|
| 토큰 밖 색상 | computed style, 팔레트 추출 후 ΔE 비교 | 토큰과의 ΔE 10 이하(초기값) |
| 텍스트 대비 | WCAG 계산, DESIGN.md lint | 본문 4.5:1, 큰 글자 3:1 |
| 폰트 | 화이트리스트 대조(Pretendard, Noto Sans KR 등) | 라이선스가 확인된 폰트만 허용 |
| 모바일 가독성 | 360px 렌더 후 최소 글자 크기 측정 | 약 12px 이상 |
| 광고 문구 | 업종별 금지 표현 사전 + LLM 검토 | 과장·오인 표현 차단 |
| 레퍼런스 유사도 | 이미지 임베딩 유사도 | 임계값을 넘으면 차단(복제 방지) |

### 7-7. 웨비나형 GTM(라이브 퍼널 벤치마킹)

1. 모집: 숏폼·블로그 → 격주 90분 웨비나
2. 리마인더: 알림톡 D-1, 1시간 전, 10분 전
3. 라이브 중 **"내 가게 홍보물 1장 즉석 생성"**(채팅으로 업종 입력)
4. 종료 30분 전 폼 공개: 템플릿 팩 + 14일 체험
5. 24시간 안에 첫 콘텐츠 자동 발행
6. 7일 내 결제 시 할인
7. 월 1회 셋업 워크숍 업셀

목표 KPI [추정]: 등록 → 참석 45%, 폼 제출 ÷ 피크 동접 25%, 활성화 60%, 체험 → 유료 15%
